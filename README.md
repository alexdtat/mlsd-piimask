# PIIMask

PIIMask готовит русскоязычные обращения поддержки к суммаризации. Цель MVP — локально находить имена, телефоны и email, возвращать символьные диапазоны и текст с масками. Первый пилот проводится офлайн на CPU.

Проект курса «Проектирование систем машинного обучения» (ИТМО, AI Talent Hub, осень 2026).
Автор: Татьяненко Алексей Дмитриевич.

Текущий бейзлайн поддерживает стандартные форматы телефонов и email. Детектор имён предусмотрен в плане моделирования.

## Установка для разработки

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pre-commit install
```

Проверка кода

```bash
pre-commit run --all-files
```

Сырые CSV хранятся локально в `data/raw/`. Отчёты в `docs/` содержат агрегаты.
